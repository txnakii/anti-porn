This project is an open-source content filtering tool designed to help users block access to adult and pornographic websites for a user-defined period of time. Its main purpose is to support focus, self-discipline, and healthier digital habits by providing a more persistent filtering system than traditional browser extensions.

The application is written in Python and is designed to run as a Windows Service. It can automatically restart itself after system reboot and includes a self-healing mechanism that helps keep the protection active during the selected lock period. The filter remains enabled until the timer set by the user expires.

Main Features:

* Blocks pornographic and adult content websites
* Runs automatically on Windows startup
* Windows Service support
* Time-based lock system
* Self-recovery if the process is terminated
* Open-source and fully inspectable code
* Customizable blacklist system

This project is fully open source. All source code can be reviewed for transparency and educational purposes. The application does not collect personal data, does not send information to external servers, and is not intended for malicious use.

Because the software uses persistence-related features such as Windows Services and automatic recovery mechanisms, some antivirus software may flag certain behaviors as suspicious. This is a common side effect of applications that are designed to remain active and resistant to accidental removal.

The goal of this project is not surveillance or control over other users, but to provide individuals with a stronger tool for enforcing their own digital boundaries and maintaining long-term focus.
